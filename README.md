# Nifty100 Financial Intelligence

## Overview

Financial analytics platform built using Python.

## Features

- ETL Pipeline
- SQLite Database
- Data Validation
- Financial Ratio Engine
- CAGR Calculation
- Cashflow KPIs
- Company Quality Score
- Company Dashboard
- KPI Dashboard
- Sector Dashboard
- Top Companies Chart
- Sector Report
- Financial Report Generator

## Project Structure

data/
src/
exports/
db/
tests/

## Technologies

- Python
- Pandas
- SQLite
- Matplotlib
- Pytest

## Outputs

- Financial Report CSV
- Sector Report CSV
- Quality Score Charts

## Run

```bash
python app.py
```

or

```bash
python -m src.dashboard.company_dashboard
```
